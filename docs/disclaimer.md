# Disclaimer

This chatbot provides **factual information only** about selected HDFC Mutual Fund
schemes as listed on Groww's public pages. It is a hobby/prototype project built
for the Learning in Public challenge.

- This tool does **not** provide investment advice, recommendations, or opinions.
- It does **not** suggest whether you should buy, sell, or hold any mutual fund.
- It does **not** compute, compare, or predict returns or performance.
- All facts are sourced from public Groww scheme pages at the time of data ingestion.
  Data may be outdated; always verify from the official scheme page before acting.
- This tool does **not** collect or store any personal information (PAN, Aadhaar,
  account numbers, phone numbers, emails, or OTPs).

**Mutual Fund investments are subject to market risks. Please read all scheme-related
documents carefully before investing.**

For authoritative information, visit:
- [groww.in/mutual-funds](https://groww.in/mutual-funds)
- [SEBI Investor Education](https://investor.sebi.gov.in)
- [AMFI India](https://www.amfiindia.com)
